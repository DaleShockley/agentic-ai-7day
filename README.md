# Agentic AI: 7-Day Build Challenge

My hands-on journey building agentic AI automations with Claude Code, working toward an **AI Technical Program Manager** role.

I'm following the free [Agentic AI: 7-Day Build Challenge](https://buildwithagents.vercel.app/), with every build day adding a piece of one capstone: a **TPM Reporting & Portfolio Builder** that turns project inputs into status reports, risk registers and charters. Each build also gets a TPM-style write-up covering scope, architecture, risks, metrics and a retro, so this repo shows both what I built and how I'd run it as a program.
