# Day 1: Status Report Drafter

Drafts a weekly executive status report for the fictional **Project Atlas** from the raw inputs in `../sample-project/`.

## Folder map
- `workflows/status-report.md`: the recipe. Follow it step by step when asked to draft a report.
- `reference/rag-rubric.md`: the RAG rules. Apply them exactly; don't use judgment where a rule exists.
- `reference/report-template.md`: the report layout.
- `reports/`: draft reports (output).
- `state/`: JSON snapshots, one per week, used for week-over-week comparison.

## Rules
- **Drafts only.** Never send, post or share a report. A human reviews every draft.
- **Never invent data.** If an input is missing or unclear, say so in the report.
- Fictional sample data only. No real company or employer names.
